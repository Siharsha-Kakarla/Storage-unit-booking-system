# Storage-unit-booking-system
**Overview:**
The Storage Unit Booking System enables customers to search storage units and book storage units by paying them online. Administartors can manage units and bookings

**Features:**
1. User registration
2. User Login
3. Search Storage Units
4. View Storage unit details
5. Create booking
6. Payment processing
7. Booking confirmation
8. Admin storage management

**Technology stack:**
1. Front end: Node.js
2. Backend: Phyton
3. Database:MongoDB
4. Deployment: AWS EC2

**Architecture**
1. Customers -> Storage Unit Booking system (Register, login, Search, create booking)-> MongoDB Database-> Payment service
2. Administrator -> Storage unit booking system (Login, Add storage units)

**Known Limitations:**

2. Basic form validation
