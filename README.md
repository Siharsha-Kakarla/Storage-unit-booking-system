# Storage-unit-booking-system
**Overview:**
The Storage Unit Booking System enables customers to search storage units and book storage units by paying them online. Administartors can manage units and bookings

**Features:**
User registration
User Login
Search Storage Units
View Storage unit details
Create booking
Payment processing
Booking confirmation
Admin storage management

**Technology stack:**
Front end: Node.js
Backend: Phyton
Database:MongoDB
Deployment: AWS EC2

**Architecture**
Customers -> Storage Unit Booking system (Register, login, Search, create booking)-> MongoDB Database-> Payment service 
Administrator -> Storage unit booking system (Login, Add storage units)
